# C++ Systems & GPU Kernels Mastery — Digital Book & Lab

An interactive digital textbook and live execution environment built with Next.js (App Router), TypeScript, and Tailwind CSS.

## 🚀 Running the Web Lab

### 1. Prerequisites
- **Node.js**: 18.x or 20.x LTS installed
- **C++ Compiler**: `clang++` or `g++` (for compiling code via `/api/run`)
- **CUDA Toolkit** (Optional, for GPU compilation): `nvcc` installed in your `PATH`

### 2. Quickstart
```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000).

## 🛠️ Key Capabilities
- **Three Track Navigation**: C++ Systems (Module 1, 20 Chapters), CUDA Architecture (Modules 2-7, 21 Topics), and GPU Kernels (28 Kernels).
- **Interactive Architecture Schematics**: Data-driven SVG diagrams for memory layouts, cache line alignment, and warp execution.
- **Integrated Sandboxes**: Multi-playground execution for C++ (`playground.cpp`), CUDA (`playground.cu`), and Kernel benchmarking (`playground_kernel.cu`).
- **Personal Annotations**: In-browser note taking and chapter bookmarking.
